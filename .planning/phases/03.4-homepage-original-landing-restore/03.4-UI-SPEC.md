# Phase 03.4 - UI Design Contract

> Visual and interaction contract for restoring the homepage to its original landing-page baseline.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none |
| Icon library | lucide-react |
| Font | Inter |

### Source Baseline

- Use the original homepage from commit `42a3af0` as the visual source of truth.
- Keep the existing Tailwind utility approach.
- Preserve Chinese copy.
- Do not keep any of the 03.2 or 03.3 homepage hero behavior, styling, or interaction hints.

---

## Layout Contract

### Hero

- Single centered hero.
- Navbar stays fixed at the top.
- Headline, supporting copy, and CTA appear above the preview block.
- The preview block is a simple bordered placeholder area, not a product-render surface and not a live 3D viewer.

### Preview Block

- Aspect ratio: `video` style (`aspect-video`).
- Neutral slate placeholder background.
- Centered `Box` icon plus the text `3D 预览区域`.
- No chips.
- No loading copy.
- No fallback copy.
- No drag/zoom hints.
- No canvas.

### Sections Below

- Restore the original three feature cards beneath the hero.
- Keep the original CTA section and footer structure.
- Do not introduce new supporting sections, split-layout hero variations, or product-photo framing.

## Style Rules

- Keep the original simple marketing tone.
- Keep orange reserved for actionable emphasis and icon accents.
- Prefer the original rounded-card and placeholder styling over premium-render presentation.
- Do not add realism cues, studio lighting language, or product-parameter labels.
- Do not treat the hero as a product showcase; treat it as a straightforward landing page.

---

## Responsive Contract

Target checkpoints: `375px`, `768px`, `1024px`, `1440px`

### Rules

- Hero remains centered at all supported breakpoints.
- CTA buttons stack on mobile exactly as the original page intended.
- Placeholder block remains readable and centered on mobile.
- Feature cards collapse to one column on smaller screens.
- No horizontal scroll.

---

## Testing Implications

- Route-level tests should assert the restored hero copy, CTA labels, and the `3D 预览区域` placeholder.
- Tests should assert that `HeroPreview`-specific copy or structures are no longer part of the homepage contract.
- Browser coverage is optional if route/component coverage already locks the restored baseline clearly.
