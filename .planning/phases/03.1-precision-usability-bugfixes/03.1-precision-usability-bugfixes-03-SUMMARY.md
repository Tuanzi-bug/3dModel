# Phase 03.1 Plan 03 Summary

**Viewport deselection is now stable, and camera recovery lives behind explicit focus/zoom controls**

## Accomplishments

- Extended `ViewPresetToolbar` with `聚焦选中`、`放大`、`缩小` actions while keeping the existing preset-view controls.
- Refactored `ViewportCanvas` so preset framing, selected-node focus, and zoom are explicit camera commands instead of automatic reactions to `selectedNodeId`.
- Added component coverage that locks both the toolbar API and the “deselect without camera jump” behavior.
