## Snapping behavior

### Q1: How should snapping trigger during movement?

| Option | Description | Selected |
|--------|-------------|----------|
| 松手时再吸附 | Drag stays manual and snap resolves on release | ✓ |
| 实时吸附，但明显减弱 | Keep live snapping with smaller thresholds | |
| 加吸附开关/按键 | Make snapping a separate mode or toggle | |

**User's choice:** 松手时再吸附
**Notes:** The current real-time snapping makes components move too fast and hard to align precisely.

### Q2: What should happen on release?

| Option | Description | Selected |
|--------|-------------|----------|
| 组件吸附 + 网格吸附 | Try component anchors first, then fall back to grid | ✓ |
| 只做组件吸附 | Only component-to-component anchors | |
| 只做组件吸附，网格保留为视觉参考 | Grid stays visible but never snaps | |

**User's choice:** 组件吸附 + 网格吸附
**Notes:** The user wants both behaviors, but anchor snapping should win before grid fallback.

## CSV export compatibility

### Q1: How should export compatibility be fixed?

| Option | Description | Selected |
|--------|-------------|----------|
| 导出 Excel 兼容 CSV | Keep `.csv` and make it open correctly in Excel | ✓ |
| 改成 .txt / TSV | Simpler fallback text export | |
| 直接导出 .xlsx | Add a native spreadsheet format | |

**User's choice:** 导出 Excel 兼容 CSV
**Notes:** The user does not want a format change; the issue is compatibility, not capability.

### Q2: What delimiter should the CSV use?

| Option | Description | Selected |
|--------|-------------|----------|
| 逗号 CSV | Standard CSV delimiter | ✓ |
| 制表符分隔 | TSV-like export for readability | |

**User's choice:** 逗号 CSV
**Notes:** The file should stay a standard comma-delimited CSV.

## Viewport focus and zoom

### Q1: What should happen when clicking empty space?

| Option | Description | Selected |
|--------|-------------|----------|
| 只取消选中，不改相机 | Deselect only, no camera movement | ✓ |
| 取消选中并回到整景视图 | Deselect and zoom back out | |
| 点击空白时聚焦最近对象 | Deselect and refocus another target | |

**User's choice:** 只取消选中，不改相机
**Notes:** The current camera jump is the problem; empty-space clicks should not reframe the scene.

### Q2: How should focus and zoom be exposed?

| Option | Description | Selected |
|--------|-------------|----------|
| 工具栏按钮：聚焦选中 + 放大 + 缩小 | Explicit viewport controls | ✓ |
| 双击组件聚焦 + 鼠标滚轮继续缩放 | Gesture-led interaction | |
| 两者都要 | Buttons and gesture support together | |

**User's choice:** 工具栏按钮：聚焦选中 + 放大 + 缩小
**Notes:** The user prefers direct, visible controls in the current viewport chrome.
