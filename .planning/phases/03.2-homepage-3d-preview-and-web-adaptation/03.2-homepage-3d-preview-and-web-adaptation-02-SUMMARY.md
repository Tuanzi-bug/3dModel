# Phase 03.2 Plan 02 Summary

**Lightweight landing-page 3D scene with rotate/zoom controls and a return-to-showcase camera contract**

## Accomplishments

- Added a dedicated `HeroPreviewScene` using R3F and Drei that renders a simplified product-adjacent shelf form rather than copying the editor viewport.
- Constrained the controls to rotate and zoom only, disabled pan, and added idle recovery so the camera returns to its default marketing angle before auto-rotation resumes.
- Hooked the shell to the real scene by default while keeping explicit WebGL fallback and reduced-motion auto-rotation suppression intact.
