# 3D 模块化设计工具 — 产品方案书

> 版本：v1.0
> 日期：2026-03-23

---

## 一、产品简介

一款基于浏览器的 **3D 在线设计工具**，用户无需安装任何软件，打开网页即可快速设计模块化框架结构（如展示架、收纳架、陈列架等）。支持从模板快速出方案，也支持从零自由搭建，所见即所得。

## 二、核心功能

### 2.1 模板快速设计

用户选择预设模板，调整参数即可快速生成 3D 方案：

| 功能 | 说明 |
|------|------|
| 模板库 | 提供 6 种常见结构：单层架、多层架、转角架、L 型架、靠墙架、独立架 |
| 尺寸调节 | 自由设定长、宽、高，实时看到 3D 效果变化 |
| 组件更换 | 可切换光轴直径（6mm / 8mm / 13mm）、层板材质（木质 / 亚克力 / 金属）、连接件类型 |
| 实时预览 | 3D 视图支持 360° 旋转、缩放、平移，任意角度查看设计效果 |

### 2.2 自由搭建设计

面向有创意需求的用户，从零开始搭建：

| 功能 | 说明 |
|------|------|
| 组件库 | 提供全部基础组件：光轴、十字夹、固定环、三通接头、层板、灯带、背板 |
| 拖拽操作 | 从组件库拖入 3D 场景，直接放置 |
| 自由编辑 | 选中组件后可移动位置、旋转方向、调整参数 |
| 智能吸附 | 组件靠近时自动对齐吸附，辅助精确搭建 |

### 2.3 设计管理

| 功能 | 说明 |
|------|------|
| 账号系统 | 邮箱注册登录，设计数据云端保存 |
| 我的设计 | 设计列表带缩略图预览，支持重命名、删除 |
| 随时继续 | 换设备也能打开之前的设计继续编辑 |
| 自动保存 | 编辑过程自动保存，不怕意外关闭丢失进度 |
| 撤销/重做 | 支持多步撤销和重做，操作无后顾之忧 |

## 三、用户使用流程

```
注册/登录 → 进入"我的设计"
  → 新建设计：选择模板 或 从零搭建
  → 在 3D 编辑器中调整设计
  → 自动保存 / 手动保存
  → 下次登录继续编辑
```

## 四、界面预览

编辑器采用专业设计软件的经典三栏布局：

```
┌──────────────────────────────────────────────┐
│            工具栏（保存、撤销、设计名称）        │
├────────┬─────────────────────────┬───────────┤
│        │                         │           │
│ 组件/   │     3D 预览窗口         │  属性调节  │
│ 模板列表│   可旋转/缩放/平移查看    │  面板     │
│        │                         │           │
│        │                         │ - 尺寸    │
│        │                         │ - 材质    │
│        │                         │ - 直径    │
│        │                         │           │
├────────┴─────────────────────────┴───────────┤
│               状态栏（组件数量等）              │
└──────────────────────────────────────────────┘
```

- **左栏**：模板选择或组件库浏览
- **中央**：3D 实时预览，支持任意角度查看
- **右栏**：选中组件后显示可调参数（尺寸、材质等）

## 五、交付计划

### 第一阶段（MVP）

**交付内容**：
- 用户注册、登录功能
- 模板快速设计（6 种预设模板 + 参数调节 + 3D 预览）
- 设计保存/加载/删除
- 自动保存 + 撤销/重做
- 3D 视角控制（旋转、缩放、平移）

**用户可以**：注册账号 → 选模板 → 调参数看效果 → 保存设计 → 下次继续

### 第二阶段

**交付内容**：
- 从零自由搭建模式
- 拖拽放置组件
- 选中组件移动/旋转/复制/删除
- 快捷键操作
- 模板模式与自由搭建模式切换

**用户可以**：不依赖模板，从零自由组合各种组件搭建任意结构

### 第三阶段

**交付内容**：
- 组件自动吸附对齐
- 灯带、背板等装饰组件
- 尺寸标注显示
- 预设视角快捷切换（正面/俯视/侧面）
- 导出 BOM 清单（零件列表 + 数量）

**用户可以**：精确搭建复杂结构，并导出零件采购清单

### 第四阶段（远期）

**交付内容**：
- 微信小程序版本
- 微信扫码登录，与网页版账号互通
- 手机/平板上也能查看和编辑设计

**用户可以**：在微信中直接打开设计工具，随时随地查看和修改方案

## 六、技术亮点

| 亮点 | 用户价值 |
|------|---------|
| 纯浏览器运行 | 无需下载安装，打开即用 |
| 实时 3D 渲染 | 所见即所得，直观高效 |
| 云端保存 | 换电脑也能继续，数据不丢失 |
| 自动保存 | 编辑实时保存，无需手动操作 |
| 模板 + 自由搭建 | 新手用模板快速上手，进阶用户自由创作 |
| 跨端扩展 | 架构预留小程序接入能力，后续无需重写核心逻辑 |

## 七、运行环境要求

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome / Edge / Safari / Firefox（最新两个大版本） |
| 设备 | 桌面电脑（推荐），需支持 WebGL 2.0 |
| 网络 | 需联网（设计数据存储在云端） |
| 小程序 | 微信 8.0+（第四阶段） |
